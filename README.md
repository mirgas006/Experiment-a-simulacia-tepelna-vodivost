Tento projekt vznikol ako spracovanie výberovej úlohy na predmete Fyzikálne praktikum 1 a zároveň poslúžil ako zápočtový projekt do predmetu Python pre fyzikov.  
Súčasťou protokolu je zadanie (experimentálne zmeranie dát vedenia tepla v medenej tyči) popis experimentálnej aparatúry a následná numerická simulácia, ktorej výsledkom je získaná hodnota tepelnej vodivosti.
